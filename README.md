# 영어 공부

유튜브로 배운 내용을 정리하고, 폰으로 출퇴근길에 복습하는 시스템.

## 앱 구성
| 탭 | 내용 |
|---|---|
| 카드 | 단어·표현·패턴을 한 곳에서 넘겨 봄. 위쪽 필터로 종류, 오답노트, 즐겨찾기, 교재 과(1과, 2과…)를 고름. 즐겨찾기는 카드 오른쪽 위 별. 카드와 목록 전환 가능. 🔊 버튼으로 앞면과 예문 발음 듣기(폰 내장 음성) |
| 듣기 | 카드 탭 오른쪽 위 헤드폰 버튼. 고른 범위를 앞면 → 뜻 → 예문 영어 → 해석 순서로 자동으로 읽어 줌. 해석 읽기·영어 한 번 더·속도 선택. 재생 중엔 화면이 켜진 채 유지(화면이 꺼지면 멈춤) |
| 시험 | 예문의 빈칸을 맞힘. 방식은 타이핑(원형·작은 오타·아포스트로피 생략도 정답, 그 문장에서 쓰인 형태를 함께 보여 줌), 보기 4개 중 선택, 문장 배열(해석을 보고 단어를 눌러 예문 전체를 순서대로 완성), 받아쓰기(문장을 듣고 빈칸을 들린 형태 그대로 입력, 해석은 가려 둠). 범위에서 교재 과를 고를 수 있음. 해석에서 강조된 부분이 힌트. "정답 보기"로 넘긴 문제와 틀린 문제는 오답노트에 자동으로 들어가고 다시 맞히면 빠짐. 많이 틀린 카드가 더 자주 출제됨 |
| 문법 | 개념 문서. 교재 과 순서대로 부별로 묶여 있음. 문서 끝에서 이전·다음 과로 넘어가거나 그 과의 카드·시험으로 바로 감 |
| 기록·설정 | 카드 탭 오른쪽 위 버튼. 발음 속도, 카드 수, 푼 문제·정답률·자주 틀리는 카드, 즐겨찾기·오답노트·기록 백업·복원 |

## 흐름
1. Claude에게 공부한 내용을 말하면 `notes/` (외울 것) 또는 `grammar/` (이해할 것)에 마크다운으로 정리됨
2. `npm run build` → `docs/data.json`, `docs/grammar.json` 생성
3. `npm run publish` → GitHub에 푸시, 1분쯤 뒤 Pages 갱신
4. 폰에서 https://e0ho.github.io/english-study/ 열기 (홈 화면에 추가해 두면 앱처럼 열리고 오프라인도 동작)

## 로컬에서 앱 확인
```bash
npm run build && npm run serve
```
그 다음 http://localhost:8080 접속.
