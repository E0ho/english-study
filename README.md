# 영어 공부

유튜브로 배운 내용을 정리하고, 폰으로 출퇴근길에 복습하는 시스템.

## 앱 구성
| 탭 | 내용 |
|---|---|
| 홈 | 앱을 열면 보이는 화면. 날짜·인사, 연속 학습일(🔥), 이번 주 학습 표시, **오늘의 학습** 시작 카드(지금 레벨 색), 빠른 연습(문장 조립·영작·받아쓰기·듣기 모드·오답노트·카드), 지금 레벨 진도와 다음 과 3개 |
| 코스 | 3년 커리큘럼 116과. 레벨 1 기초(OPIc IM) → 2 중급(IH) → 3 고급(AL) → 4 현지 생활. 레벨을 고르면 부별 과 목록과 진도가 보이고, 과를 누르면 문법 읽기·카드·연습·듣기로 감. 자료가 없는 과는 "준비 중" |
| 오늘의 학습 | 한 세트 10~13단계. 지금 과의 새 표현 3개 소개(발음 들려줌) → 그 표현으로 문장 조립 → 오답노트·예전에 배운 카드 빈칸 채우기 → 영작 → 받아쓰기 → 결과(정답 수, 연속 학습일, 오늘 배운 표현). 끝내면 그날이 학습한 날로 기록됨 |
| 연습 | 방식과 범위를 골라 10문제. 방식은 문장 조립(해석을 보고 단어를 눌러 문장 완성), 영작(해석을 보고 문장 전체 타이핑, 작은 오타는 정답), 빈칸 채우기(원형·작은 오타도 정답), 보기 고르기, 받아쓰기(듣고 빈칸을 들린 형태 그대로 입력). 범위 버튼을 누르면 전체·오답노트·즐겨찾기·종류·교재 과 목록이 올라옴. 틀린 문제와 "정답 보기"로 넘긴 문제는 오답노트에 들어가고 다시 맞히면 빠짐 |
| 카드 | 단어·표현·패턴을 넘겨 봄. 범위 버튼으로 종류, 오답노트, 즐겨찾기, 교재 과, 직접 정리한 카드를 고름. 즐겨찾기는 별. 카드와 목록 전환. 🔊 버튼으로 발음 듣기(폰 내장 음성). 오른쪽 위 헤드폰 버튼이 듣기 모드(고른 범위를 앞면 → 뜻 → 예문 → 해석 순서로 자동 재생) |
| 문법 | 개념 문서. 교재 과 순서대로 부별로 묶여 있음. 문서 끝에서 이전·다음 과로 넘어가거나 그 과의 카드·시험으로 바로 감 |
| 기록·설정 | 홈 오른쪽 위 버튼. 연속 학습·학습한 날·배운 카드·익힌 카드, 자주 틀리는 카드, 발음 속도, 기록 백업·복원 |

"배운 카드"는 오늘의 학습에서 소개받았거나 문제로 한 번이라도 나온 카드, "익힌 카드"는 2번 이상 맞히고 맞힌 횟수가 틀린 횟수보다 많은 카드. 평가 버튼은 없고 문제 결과로만 자동 판단함.

## 흐름
1. Claude에게 공부한 내용을 말하면 `notes/` (외울 것) 또는 `grammar/` (이해할 것)에 마크다운으로 정리됨
2. `npm run build` → `docs/data.json`, `docs/grammar.json` 생성
3. `npm run publish` → GitHub에 푸시, 1분쯤 뒤 Pages 갱신
4. 폰에서 https://e0ho.github.io/english-study/ 열기 (홈 화면에 추가해 두면 앱처럼 열리고 오프라인도 동작)

## 학습 기록 동기화 (Firebase, 무료)
공부 자료는 깃허브에 있지만, 학습 기록(즐겨찾기·오답노트·정답 횟수·학습한 날)은 폰 브라우저에만 저장된다. Firebase 를 붙이면 기록이 서버에 올라가고 다른 폰·PC 에서도 이어서 공부할 수 있다. Firebase 무료(Spark) 플랜은 카드 등록이 없어서 요금이 나갈 수 없다. 이 앱이 쓰는 양은 무료 한도의 1% 미만.

한 번만 하면 되는 설정 (10분):
1. https://console.firebase.google.com 에서 **프로젝트 추가** → 이름은 아무거나 (예: english-study). Google 애널리틱스는 끈다.
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법 → 이메일/비밀번호** 를 켠다. (이메일 링크는 끈 채로)
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치는 asia-northeast3 (서울) → **프로덕션 모드**로 시작.
4. Firestore 의 **규칙** 탭에 아래를 붙여 넣고 게시한다. 본인 uid 의 문서만 읽고 쓸 수 있게 하는 규칙이다.
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. **프로젝트 설정(톱니) → 일반 → 내 앱 → 웹 앱 추가(</>)** → 닉네임 아무거나, 호스팅은 체크 안 함 → 나오는 `firebaseConfig` 값을 `docs/firebase-config.js` 의 `window.FIREBASE_CONFIG = { ... }` 에 넣는다. 이 값은 비밀이 아니라 깃허브에 올려도 된다 (보안은 4번 규칙이 담당).
6. `npm run publish` 로 배포한 뒤, 앱의 **기록·설정 → 동기화**에서 이메일·비밀번호로 회원가입한다. 다른 기기에서는 같은 계정으로 로그인하면 된다.

동작 방식: 폰 저장소가 원본이고, 기록이 바뀌면 몇 초 뒤 `users/{uid}` 문서 하나에 통째로 올린다. 다른 기기에서 바뀌면 실시간으로 받아서 합친다 (즐겨찾기는 하나라도 켜져 있으면 켜짐, 오답은 합집합, 횟수는 큰 쪽). 로그아웃해도 폰의 기록은 남는다. 오프라인이면 폰에만 저장했다가 다시 연결되면 올린다.

