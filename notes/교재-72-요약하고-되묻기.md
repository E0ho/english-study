## 패턴
### So what you're saying is ~
- 뜻: 그러니까 ~라는 말씀이네요
- 예문: {{So what you're saying is}} the problem isn't the technology, it's how we use it.
  - 해석: {{그러니까}} 문제는 기술이 아니라 그걸 어떻게 쓰느냐라는 말씀이네요.
  - 문법: 요약하기 (So what you're saying is + 문장: 긴 말을 한 줄로 되돌려 주기)
  - 문법: 간접의문문 (how we use it: 의문사 + 주어 + 동사)
- 예문: {{So what you're saying is}} we should wait until next quarter?
  - 해석: {{그러니까}} 다음 분기까지 기다려야 한다는 말씀이세요?
  - 문법: 요약하기 (평서문 어순 + 끝을 올려 확인 질문으로)
  - 문법: 조동사 should (should wait: 해야 한다)
- 메모: 상대가 쓴 단어를 그대로 쓰지 말고 내 말로 바꾼다. 끝을 올리거나 Is that right? 을 붙인다.

### If I understand correctly, ~
- 뜻: 제가 제대로 이해했다면, ~
- 예문: {{If I understand correctly}}, you're not against remote work itself, just against doing it five days a week.
  - 해석: {{제가 제대로 이해했다면}}, 재택근무 자체가 아니라 주 5일 전부 재택으로 하는 것에 반대하시는 거네요.
  - 문법: 요약하기 (If I understand correctly: 격식 있는 조심스러운 요약)
  - 문법: 동명사 (against doing: 전치사 against 뒤 동명사)
- 예문: {{If I understand correctly}}, the deadline moved, but the budget didn't.
  - 해석: {{제가 제대로 이해했다면}}, 마감은 옮겨졌는데 예산은 안 바뀐 거죠.
  - 문법: 요약하기 (If I understand correctly + 쉼표 + 요약 문장)
  - 문법: 과거시제 (moved, didn't: 이미 정해진 일)
- 메모: 회의나 윗사람과 말할 때. 뒤에는 의문문이 아니라 요약 문장이 온다.

### Let me make sure I've got this right.
- 뜻: 제가 제대로 이해했는지 확인할게요.
- 예문: {{Let me make sure I've got this right}}. You want to cut the meeting to thirty minutes and move it to Friday?
  - 해석: {{제가 제대로 이해했는지 확인할게요}}. 회의를 30분으로 줄이고 금요일로 옮기고 싶으신 거죠?
  - 문법: 확인 질문 (Let me make sure I've got this right: 복잡한 설명 뒤 멈추고 정리)
  - 문법: 사역동사 (let me + 동사원형: 제가 ~할게요)
- 예문: {{Let me make sure I've got this right}}. The first option is cheaper, but the second one is faster.
  - 해석: {{제가 제대로 이해했는지 볼게요}}. 첫 번째가 더 싸고, 두 번째가 더 빠르다는 거네요.
  - 문법: 확인 질문 (선언 뒤에 번호 매기듯 정리)
  - 문법: 비교급 (cheaper, faster: 더 싼, 더 빠른)
- 메모: I've got this right 가 정해진 표현. 요약이 두 가지 이상일 때 쓴다.

### Does that mean ~?
- 뜻: 그 말은 ~라는 건가요?
- 예문: {{Does that mean}} we're putting the hiring plan on hold?
  - 해석: {{그럼}} 채용 계획은 보류한다는 {{건가요}}?
  - 문법: 되묻기 (Does that mean + 평서문 어순: 상대 말에서 따라 나오는 결론 확인)
  - 문법: 현재진행형 (we're putting: 지금 하기로 한 일)
- 예문: {{Does that mean}} you'd be okay with a hybrid schedule?
  - 해석: {{그 말은}} 하이브리드 일정이면 괜찮으시다는 {{건가요}}?
  - 문법: 되묻기 (Does that mean: 숨은 뜻 끌어내기)
  - 문법: 가정법 (you'd be okay: 그렇다면 괜찮을 것이다)
- 메모: 요약이 아니라 다음 결론을 묻는 말. 뒤는 의문문 어순이 아니라 평서문 어순.

### Correct me if I'm wrong, but ~
- 뜻: 제가 틀렸으면 고쳐 주세요, 근데 ~
- 예문: {{Correct me if I'm wrong, but}} didn't we already try that last year?
  - 해석: {{제가 틀렸으면 고쳐 주세요, 근데}} 작년에 이미 그거 해 보지 않았나요?
  - 문법: 되묻기 (Correct me if I'm wrong, but: 틀릴 수 있다는 전제를 깔고 반박)
  - 문법: 부정 의문문 (didn't we ~?: ~하지 않았나요)
- 예문: {{Correct me if I'm wrong, but}} I think you said the opposite a minute ago.
  - 해석: {{틀렸으면 말씀해 주세요, 근데}} 조금 전엔 반대로 말씀하신 것 같은데요.
  - 문법: 되묻기 (Correct me if I'm wrong: 기억이 틀릴 수 있음을 인정)
  - 문법: 명령문 (Correct me: 동사원형으로 시작)
- 메모: 뒤에는 부드러운 문장. 확신에 찬 반박과 같이 쓰면 앞말이 빈말이 된다.

### So basically, ~
- 뜻: 그러니까 기본적으로 ~
- 예문: {{So basically}}, you'd rather see media literacy classes than a ban.
  - 해석: {{그러니까 기본적으로}} 금지보다는 미디어 교육 수업을 원하시는 거네요.
  - 문법: 요약하기 (So basically: 친구 사이의 가벼운 요약)
  - 문법: 조동사 would rather (would rather A than B: B보다 A가 낫다)
- 예문: {{So basically}}, the whole plan depends on one person?
  - 해석: {{그러니까 기본적으로}} 계획 전체가 한 사람한테 달려 있다는 거예요?
  - 문법: 요약하기 (So basically + 끝 올리는 확인 질문)
  - 문법: 구동사 (depend on: ~에 달려 있다)
- 메모: So what you're saying is 의 캐주얼 버전. 회의에서는 If I understand correctly 가 낫다.

### Is that right?
- 뜻: 맞아요?
- 예문: You want the report by Friday, not Monday. {{Is that right}}?
  - 해석: 보고서를 월요일이 아니라 금요일까지 원하시는 거죠. {{맞아요}}?
  - 문법: 확인 질문 (요약 문장 뒤에 Is that right?: 짧은 확인)
  - 문법: 전치사 by (by Friday: 금요일까지)
- 예문: So the new line opens next spring. {{Is that right}}?
  - 해석: 그러니까 새 노선이 내년 봄에 열리는 거네요. {{맞아요}}?
  - 문법: 확인 질문 (So + 요약 + Is that right?)
  - 문법: 현재시제 (opens: 정해진 일정은 현재시제)
- 메모: 어떤 요약 뒤에든 붙일 수 있는 가장 짧은 확인. Right? 한 단어로 줄여도 된다.
