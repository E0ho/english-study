## 패턴
### The problem is that ~
- 뜻: 문제는 ~라는 거예요
- 예문: {{The problem is that}} the left side stopped working after just two days.
  - 해석: {{문제는}} 이틀 만에 왼쪽이 안 나온다는 {{거예요}}.
  - 문법: 명사절 접속사 that (is that + 문장: 문제의 내용)
  - 문법: 과거시제 (stopped working: 멈춘 사실)
- 예문: {{The problem is that}} the jacket is two sizes too big.
  - 해석: {{문제는}} 재킷이 두 치수나 크다는 {{거예요}}.
  - 문법: 명사절 접속사 that (is that)
  - 문법: 부사 too (two sizes too big: 두 치수만큼 너무 큰)
- 메모: 불만을 말할 때 핵심 한 문장을 이 틀에 넣으면 상대가 바로 알아듣는다.

### I've tried ~ing, but ~
- 뜻: ~해 봤는데 ~해요
- 예문: {{I've tried}} charging them fully and resetting them, but nothing has changed.
  - 해석: 완전히 충전도 {{해 보고}} 초기화도 해 봤는데 달라진 게 없어요.
  - 문법: 현재완료 (have tried: 지금까지 해 본 것)
  - 문법: 동명사 (tried charging, resetting: try + -ing)
  - 문법: 접속사 but (시도와 결과의 대조)
- 예문: {{I've tried}} restarting the app twice, but it still crashes.
  - 해석: 앱을 두 번이나 다시 {{켜 봤는데}} 여전히 꺼져요.
  - 문법: 현재완료 (have tried)
  - 문법: 동명사 (tried restarting)
- 메모: "내 잘못이 아니다"를 전하는 문장. 시도한 것 두 가지를 and 로 묶으면 좋다.

## 표현
### to be honest
- 뜻: 솔직히 말하면
- 예문: {{To be honest}}, I'm pretty disappointed, because they weren't cheap.
  - 해석: {{솔직히}} 꽤 실망스러워요, 싼 것도 아니었거든요.
  - 문법: to부정사 부사적 용법 (to be honest: 독립적으로 쓰이는 관용 부사구)
  - 문법: 접속사 because (because + 이유)
- 예문: {{To be honest}}, I expected better quality for the price.
  - 해석: {{솔직히}} 이 가격이면 더 나은 품질을 기대했어요.
  - 문법: 과거시제 (expected: 기대했던 것)
  - 문법: 비교급 (better quality)
- 메모: 감정을 말하기 전에 붙이면 공격적으로 들리지 않는다. honestly 와 같다.

## 패턴
### I'd like to return ~
- 뜻: ~을 반품하고 싶어요
- 예문: {{I'd like to return}} them and get a full refund, if that's okay.
  - 해석: 괜찮으시다면 {{반품하고}} 전액 환불받고 싶어요.
  - 문법: to부정사 명사적 용법 (would like to return: 반품하기를 원하다)
  - 문법: 접속사 if (if that's okay: 조건을 덧붙임)
- 예문: {{I'd like to return}} this jacket because it doesn't fit.
  - 해석: 안 맞아서 이 재킷을 {{반품하고 싶어요}}.
  - 문법: to부정사 명사적 용법 (would like to return)
  - 문법: 접속사 because (because + 이유)
- 메모: return = 반품하다. 환불은 get a refund, 교환은 exchange.

### I'd be willing to ~
- 뜻: ~할 의향은 있어요
- 예문: If a refund isn't possible, {{I'd be willing to}} exchange them for a new pair.
  - 해석: 환불이 안 된다면 새 제품으로 교환할 {{의향은 있어요}}.
  - 문법: 접속사 if (if + 조건절: 1순위가 안 될 때)
  - 문법: 조동사 would (would be willing: 가정 속의 의향)
- 예문: {{I'd be willing to}} pay a little extra for faster shipping.
  - 해석: 더 빠른 배송이면 돈을 조금 더 낼 {{의향은 있어요}}.
  - 문법: 조동사 would (would be willing to)
  - 문법: 비교급 (faster shipping)
- 메모: 2순위 요구를 말할 때. willing = 기꺼이 하는.

### Could you let me know ~?
- 뜻: ~을 알려 주실 수 있을까요?
- 예문: {{Could you let me know}} how I should send them back?
  - 해석: 어떻게 돌려보내면 되는지 {{알려 주실 수 있을까요}}?
  - 문법: 조동사 could (could you: 공손한 요청)
  - 문법: 간접의문문 (how I should send: how + 주어 + 동사 어순)
- 예문: {{Could you let me know}} when the refund will go through?
  - 해석: 환불이 언제 처리되는지 {{알려 주실 수 있을까요}}?
  - 문법: 조동사 could (could you)
  - 문법: 간접의문문 (when the refund will go through)
- 메모: let me know + 의문사절. 뒤는 평서문 어순이다.

### I'd appreciate it if you could ~
- 뜻: ~해 주시면 감사하겠습니다
- 예문: {{I'd appreciate it if you could}} sort this out as soon as possible.
  - 해석: 최대한 빨리 처리해 {{주시면 감사하겠습니다}}.
  - 문법: 가정법 (would appreciate it if you could: 공손한 가정형 부탁)
  - 문법: 최상급 (as soon as possible)
- 예문: {{I'd appreciate it if you could}} send a replacement this week.
  - 해석: 이번 주에 교환품을 보내 {{주시면 감사하겠습니다}}.
  - 문법: 가정법 (would appreciate it if you could)
  - 문법: 시간 표현 (this week)
- 메모: 가장 격식 있는 부탁. it 을 빼먹지 않는다. appreciate it.

## 표현
### sort out
- 뜻: 해결하다, 처리하다
- 예문: I'd appreciate it if you could {{sort this out}} as soon as possible.
  - 해석: 최대한 빨리 {{처리해}} 주시면 감사하겠습니다.
  - 문법: 구동사 (sort out: 목적어 this 가 사이에 들어감)
- 예문: Don't worry, we'll {{sort it out}} by tomorrow.
  - 해석: 걱정 마세요, 내일까지 {{해결해 드릴게요}}.
  - 문법: 구동사 (sort it out: 대명사는 반드시 사이에)
  - 문법: 미래시제 (will sort out)
- 메모: 문제를 정리해서 해결한다는 느낌. solve 보다 회화에서 훨씬 많이 쓴다.
