## 핵심 개념

"산 물건에 문제가 있어서 가게에 전화하세요"는 OPIc 롤플레이 단골입니다. 채점자가 보는 것은 **화내지 않고 차분하게, 그러나 분명하게** 요구하는가입니다. 영어권에서는 불만도 "사실 → 시도한 것 → 원하는 것" 순서로 말해야 상대가 움직입니다.

IH 수준의 핵심은 두 가지입니다. 첫째, **무엇을 해 봤는지**를 현재완료로 말하기(`I've tried ~`). 이게 있어야 "본인 실수가 아니다"가 전달됩니다. 둘째, 원하는 것을 **1순위·2순위로** 말하기(`I'd like ~. If not, I'd be willing to ~`). 그리고 `Could you ~?`, `I'd appreciate it if ~` 같은 공손한 요청으로 끝냅니다.

## 한눈에 보기

| 순서 | 내용 | 틀 |
|---|---|---|
| 1 용건 | 무엇을 언제 샀는지 | I'm calling about ~ |
| 2 정보 | 주문 번호·도착일 | The order number is ~ |
| 3 문제 | 뭐가 잘못됐는지 | The problem is that ~ |
| 4 시도 | 내가 해 본 것 | I've tried ~ing, but ~ |
| 5 감정 | 짧게 한 문장 | To be honest, I'm ~ |
| 6 요구 | 1순위 | I'd like to return ~ |
| 7 대안 | 2순위 | I'd be willing to ~ |
| 8 마무리 | 방법 묻기·부탁 | Could you let me know ~? |

## 모범 답안

상황: 온라인으로 산 헤드폰이 이틀 만에 고장 나서 고객센터에 전화한다.

> Hi, I'm calling about a pair of headphones I bought from your website last week.
> → 안녕하세요, 지난주에 홈페이지에서 산 헤드폰 때문에 전화드렸어요.

> The order number is 48213, and they arrived on Monday.
> → 주문 번호는 48213이고, 월요일에 도착했어요.

> The problem is that the left side stopped working after just two days.
> → 문제는 이틀 만에 왼쪽이 안 나온다는 거예요.

> I've tried charging them fully and resetting them, but nothing has changed.
> → 완전히 충전도 해 보고 초기화도 해 봤는데 달라진 게 없어요.

> To be honest, I'm pretty disappointed, because they weren't cheap.
> → 솔직히 꽤 실망스러워요, 싼 것도 아니었거든요.

> I'd like to return them and get a full refund, if that's okay.
> → 괜찮으시다면 반품하고 전액 환불받고 싶어요.

> If a refund isn't possible, I'd be willing to exchange them for a new pair.
> → 환불이 안 된다면 새 제품으로 교환할 의향은 있어요.

> I still have the receipt and the original box.
> → 영수증이랑 원래 상자도 아직 갖고 있어요.

> Could you let me know how I should send them back?
> → 어떻게 돌려보내면 되는지 알려 주실 수 있을까요?

> I'd appreciate it if you could sort this out as soon as possible.
> → 최대한 빨리 처리해 주시면 감사하겠습니다.

## 바꿔 쓰는 법

- **물건**: `a pair of headphones` → `a jacket`, `a coffee maker`, `a phone case`. 바지·신발·안경도 `a pair of ~`.
- **문제**: `the left side stopped working` → `it came in the wrong size`, `there's a crack on the screen`, `it doesn't match the picture online`, `one of the buttons is missing`.
- **시도한 것**: `charging them and resetting them` → `following the instructions`, `washing it once`, `checking the settings`. 옷이면 시도 대신 `I haven't even worn it yet.`
- **감정**: 한 문장만. `I'm pretty disappointed` → `I'm a bit frustrated`, `I was really looking forward to using it`. 화내는 단어(terrible, worst)는 피합니다.
- **요구**: `a full refund` → `a replacement`, `a partial refund`, `store credit`. 2순위도 꼭 넣습니다.
- **매장에서 직접 말할 때**: 첫 문장을 `Hi, I bought this here last week, and I'd like to return it.` 로 바꾸고 주문 번호 대신 `Here's the receipt.`

## 자주 하는 실수

- **This is broken. I want my money back.** 틀린 말은 아니지만 IH 롤플레이로는 너무 짧고 공격적입니다. 문제 설명과 시도한 것을 앞에 둡니다.
- **I tried to charge it but it is not working.** 해 본 것은 현재완료 `I've tried ~ing`. 결과는 `nothing has changed`, `it still doesn't work`.
- **I want to refund.** refund 는 "내가 받는 것". `get a refund` 또는 `I'd like a refund`. 상대가 하는 것은 `give me a refund`.
- **I'm so angry.** 감정은 `disappointed`, `frustrated` 정도로. 상대를 탓하는 `you sent me ~` 보다 `it arrived ~` 로 물건을 주어로 씁니다.
- 대안 없이 환불만 요구하기. `If a refund isn't possible, ~` 한 문장이 IH 와 IM 을 가릅니다.
