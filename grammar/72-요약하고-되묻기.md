## 핵심 개념

토론과 회의에서 **가장 많이 하는 일**은 내 의견 말하기가 아니라 **상대 말을 확인하는 것**입니다. 상대가 길게 설명하면 그걸 **한 문장으로 줄여서 되돌려 주고** "맞아요?" 라고 묻습니다. 이게 되면 세 가지가 한꺼번에 해결됩니다. 내가 제대로 들었는지 확인되고, 상대는 "들어 줬다" 고 느끼고, 반박할 때 **무엇에 반박하는지** 분명해집니다.

틀은 단순합니다. **요약 신호어 → 상대 말을 내 말로 → 확인 질문**. 신호어는 `So what you're saying is ~`, `If I understand correctly, ~`, `Let me make sure I've got this right.` 세 가지가 중심이고, 확인은 `Is that right?`, `Does that mean ~?` 으로 합니다. 틀렸을까 봐 걱정되면 앞에 `Correct me if I'm wrong, but ~` 을 붙입니다.

## 한눈에 보기

| 역할 | 틀 | 쓰는 때 |
|---|---|---|
| 요약 열기 | So what you're saying is ~ | 긴 말을 한 줄로 |
| 조심스러운 요약 | If I understand correctly, ~ | 격식, 회의 |
| 멈추고 정리 | Let me make sure I've got this right. | 복잡한 설명 뒤 |
| 결과 확인 | Does that mean ~? | 숨은 뜻을 끌어내기 |
| 틀릴 수 있다는 전제 | Correct me if I'm wrong, but ~ | 확신 없는 요약 |
| 짧은 확인 | Is that right? / So ~? | 어디든 |

요약은 **상대가 쓴 단어를 그대로 쓰지 않고** 내 말로 바꿉니다. 그래야 제대로 이해했는지 드러납니다. 69과의 바꿔 말하기가 여기서 쓰입니다.

## 1. 요약 열기: So what you're saying is

`So what you're saying is ~` 는 "그러니까 지금 하시는 말씀은 ~라는 거네요" 입니다. 뒤에 `that + 문장` 이 오고 that 은 거의 생략합니다. 끝을 **살짝 올려** 말하면 그 자체가 질문이 됩니다.

> So what you're saying is the problem isn't the technology, it's how we use it.
> → 그러니까 문제는 기술이 아니라 그걸 어떻게 쓰느냐라는 말씀이네요.

> So what you're saying is we should wait until next quarter?
> → 그러니까 다음 분기까지 기다려야 한다는 말씀이세요?

비슷한 말: `So basically, ~` (그러니까 기본적으로), `In other words, you think ~` (다시 말해 ~라고 생각하시는 거죠).

## 2. 조심스러운 요약: If I understand correctly

`If I understand correctly, ~` 는 "제가 제대로 이해했다면" 입니다. 회의나 윗사람과 말할 때 `So what you're saying is` 보다 **격식 있고 조심스럽습니다**. 뒤에는 요약 문장이 그대로 옵니다.

> If I understand correctly, you're not against remote work itself, just against doing it five days a week.
> → 제가 제대로 이해했다면, 재택근무 자체가 아니라 주 5일 전부 재택으로 하는 것에 반대하시는 거네요.

> If I understand correctly, the deadline moved, but the budget didn't.
> → 제가 제대로 이해했다면, 마감은 옮겨졌는데 예산은 안 바뀐 거죠.

## 3. 멈추고 정리: Let me make sure I've got this right

상대 설명이 **복잡했을 때** 대화를 잠깐 멈추는 말입니다. "제가 제대로 이해했는지 확인할게요" 라고 선언하고, 그다음 문장에서 요약을 **번호를 매기듯** 정리합니다. `I've got this right` 는 "이걸 바르게 받았다" 는 뜻입니다.

> Let me make sure I've got this right. You want to cut the meeting to thirty minutes and move it to Friday?
> → 제가 제대로 이해했는지 확인할게요. 회의를 30분으로 줄이고 금요일로 옮기고 싶으신 거죠?

> Let me make sure I've got this right. The first option is cheaper, but the second one is faster.
> → 제가 제대로 이해했는지 볼게요. 첫 번째가 더 싸고, 두 번째가 더 빠르다는 거네요.

## 4. 결과 확인: Does that mean ~?

요약이 아니라 **상대 말에서 따라 나오는 결론**을 묻는 말입니다. 상대가 "예산이 줄었어요" 라고 하면 "그럼 채용도 미뤄지는 건가요?" 처럼 **숨은 뜻**을 끌어냅니다. 상대는 "네" 또는 "아니요, 그건 아니고" 로 바로 답할 수 있습니다.

> Does that mean we're putting the hiring plan on hold?
> → 그럼 채용 계획은 보류한다는 건가요?

> Does that mean you'd be okay with a hybrid schedule?
> → 그 말은 하이브리드 일정이면 괜찮으시다는 건가요?

## 5. 틀릴 수 있다는 전제: Correct me if I'm wrong

`Correct me if I'm wrong, but ~` 은 "틀렸으면 고쳐 주세요, 근데" 입니다. **내 요약이나 기억이 틀릴 수 있다**는 걸 앞에 깔아서, 뒤의 말이 반박처럼 들려도 공격이 안 됩니다. 요약에도, 반박에도 씁니다.

> Correct me if I'm wrong, but didn't we already try that last year?
> → 제가 틀렸으면 고쳐 주세요, 근데 작년에 이미 그거 해 보지 않았나요?

> Correct me if I'm wrong, but I think you said the opposite a minute ago.
> → 틀렸으면 말씀해 주세요, 근데 조금 전엔 반대로 말씀하신 것 같은데요.

## 모범 답변

상대: "I'm not saying we should ban social media. I just think schools need to teach kids how it actually works, the algorithms, the ads, all of it. Otherwise they're just handing over their attention for free."

> So what you're saying is the problem isn't social media itself, it's that kids don't understand it.
> → 그러니까 문제는 소셜 미디어 자체가 아니라, 아이들이 그걸 이해 못 한다는 거네요.

> If I understand correctly, you'd rather see media literacy classes than a ban.
> → 제가 제대로 이해했다면, 금지보다는 미디어 교육 수업을 원하시는 거고요.

> Does that mean you'd be fine with kids using it at school, as long as they've had that class?
> → 그 말은 그 수업만 들었으면 아이들이 학교에서 써도 괜찮다는 건가요?

> Correct me if I'm wrong, but that sounds like a lot to ask of teachers who are already stretched thin.
> → 제가 틀렸으면 고쳐 주세요, 근데 그건 이미 여유가 없는 선생님들한테 너무 많은 걸 요구하는 것 같아요.

**요약 → 조심스러운 요약 → 결과 확인 → 조심스러운 반박** 으로 이어집니다. 네 문장 모두 상대 단어(`ban`, `teach`, `algorithms`)를 **내 말**(`problem isn't ~`, `media literacy`, `stretched thin`)로 바꿨습니다.

## 구별하는 요령

- 상대 말을 **줄이는** 거면 So what you're saying is. 상대 말에서 **다음 결론**을 묻는 거면 Does that mean.
- 격식이 필요하면 If I understand correctly. 친구 사이면 So basically.
- 요약이 **두 가지 이상**이면 Let me make sure I've got this right 로 멈추고 정리한다.
- 요약에 상대 단어를 그대로 쓰면 앵무새. 한두 단어는 꼭 내 말로 바꾼다.
- `Correct me if I'm wrong` 뒤에 `but` 이 거의 항상 온다.

## 자주 하는 실수

- **What you're saying is ~ 를 쉼표 없이 질문으로.** 끝을 올리거나 뒤에 Is that right? 을 붙여야 확인이 된다. 평서문으로 끝내면 단정하는 걸로 들린다.
- **If I understand correctly, is it ~? (X)** 뒤에는 의문문이 아니라 요약 문장. If I understand correctly, you want ~.
- **Let me make sure I got it right. (어색)** 회화에서는 I've got this right 가 정해진 표현.
- **Does that mean 뒤에 의문문 어순. (X)** Does that mean we are ~? 처럼 평서문 어순.
- **Correct me if I'm wrong 뒤에 확신에 찬 반박.** 이 말은 틀릴 수 있다는 전제다. 뒤에는 부드러운 문장이 어울린다.
