## 핵심 개념

영어는 생각보다 **직설을 피하는 언어**입니다. "이거 별로야"를 `It's bad.`라고 하면 무례하게 들리고, `It's kind of bad.`나 `It's not great.`라고 하면 같은 뜻인데 훨씬 부드럽습니다. 이렇게 **말의 날을 뭉툭하게 만드는 장치**를 완곡 표현(hedging)이라고 합니다.

크게 세 갈래입니다. 정도를 줄이는 말(`kind of`, `a bit`), 확신을 낮추는 말(`I'm not sure if`, `I think`), 제안을 돌려 말하는 틀(`It might be better to`, `I was wondering if`)입니다. 의견을 말하거나 부탁할 때 이게 있으면 **IH 다운 말투**가 됩니다.

## 한눈에 보기

| 표현 | 쓰임 | 예 |
|---|---|---|
| kind of / sort of | 좀, 약간 (정도 줄이기) | It's kind of expensive. |
| a bit / a little | 조금 (형용사 앞) | I'm a bit tired. |
| not really / not that | 별로, 그렇게까지는 | It's not that far. |
| I'm not sure if | ~인지 잘 모르겠는데 | I'm not sure if it's open. |
| It might be better to | ~하는 게 나을지도 | It might be better to wait. |
| I was wondering if | 혹시 ~할 수 있을까 해서 | I was wondering if you're free. |

## 1. kind of / sort of / a bit: 정도 줄이기

형용사나 동사 앞에 붙여 **"좀, 약간"**을 더합니다. `kind of`와 `sort of`는 같은 뜻이고, 말할 때는 `kinda`, `sorta`로 들립니다. `a bit`은 형용사 앞에 옵니다.

> It's kind of expensive.
> → 그거 좀 비싸.

> I sort of forgot about it.
> → 그거 깜빡 잊은 것 같아.

> I'm a bit tired today.
> → 나 오늘 좀 피곤해.

부정으로 말하면 더 부드럽습니다. "싫어"보다 **"별로 안 좋아해"**가 완곡입니다.

> I'm not really into sports.
> → 난 운동에는 별로 관심 없어.

## 2. I'm not sure if / I think: 확신 낮추기

틀릴 수도 있는 말, 상대와 다른 의견을 꺼낼 때 **앞에 완충재**를 둡니다. `I'm not sure if`는 "~인지 잘 모르겠는데", `I think`나 `I feel like`는 "내 생각엔"입니다.

> I'm not sure if that's a good idea.
> → 그게 좋은 생각인지 잘 모르겠어.

> I feel like we're running out of time.
> → 우리 시간이 부족한 것 같은데.

## 3. It might be better to / I was wondering if: 제안과 부탁 돌려 말하기

"이렇게 해"를 **"이렇게 하는 게 나을지도"**로, "해 줘"를 **"혹시 해 줄 수 있을까 해서"**로 바꾸는 틀입니다.

> It might be better to take the subway.
> → 지하철 타는 게 나을지도 몰라.

> I was wondering if I could leave a bit early.
> → 혹시 조금 일찍 가도 될까 해서요.

`I was wondering if`는 **과거형이지만 지금의 부탁**입니다. 과거형이 거리를 두어서 더 정중하게 들립니다.

## 구별하는 요령

- 형용사의 세기를 줄이려면 → **kind of, a bit**. 좋지 않다는 말은 **not great, not really** 로.
- 의견을 꺼낼 때 → **I think, I feel like, I'm not sure if** 앞에 붙이기.
- 제안 → **It might be better to**. 부탁 → **I was wondering if**.
- 완곡 표현은 **겹쳐 써도** 됩니다. `I think it might be a bit too late.` 처럼 두세 개가 자연스럽게 쌓입니다.

## 자주 하는 실수

- **It's bad. / I don't like it.** 틀린 문장은 아니지만 직설적입니다. It's not great. / I'm not a big fan.
- **kind of 를 명사 앞에 쓰기.** "일종의 ~"일 때는 a kind of 가 되어 뜻이 달라집니다. 정도를 줄일 때는 형용사·동사 앞에.
- **I was wondering if 뒤에 you can 쓰기.** 과거형으로 맞추면 더 자연스럽습니다. I was wondering if you could ~.
- **a bit 을 명사 앞에 바로 쓰기.** a bit of 가 필요합니다. a bit of time, a bit of help.
